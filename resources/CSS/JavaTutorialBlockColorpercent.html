Javascript Tutorial: change a block's color

This tutorial builds on some of the ideas of the last one where we were doing math. We will use the "document.getElementById" again in this tutorial, but this time we are going to change an element's CSS properties. If you don't know about CSS, you should read our CSS tutorials here first. When we are finished, we'll have a page that looks like this:

So let's get started! First the HTML, You don't have to, but I put in a paragraph prompting the user for a color and then a helpful hint as to what our Javascript program is setup to work with. In this case it is named HTML colors, a list of which you can find here, and hex codes.

<p>What color should this block be?</p>
<p><i>Hint: Type in a color name like 'blue' or 'purple' or a hex code like '#2594f8'</i></p>
<p><input type="text" id="inputcolor"></p>
<p><input type="button" value="Shazaam!" onclick="checkcolor()"></p>
<div id="block">
<p>heres a block</p>
</div>

I also setup a text field where the user can type in a color, naming it "inputcolor", and setup a button that will run the Javascript function that will change the CSS style, naming it "checkcolor()". As for the CSS itself, mine looks like this:

#block {
height: 100px;
width: 100px;
border:solid black 2px;
}

This sets up the basic look of the block we'll be modifying, but notice how there is nothing set for backgound color. You can set something so when the page loads there is already a color, but not defining it works just as well. You do not need to have if listed in on the style page either. Now, to change the color, we need a function that will

  • Go get the user's input
  • Go get the page element we want to modify (the block)
  • Change the element's CSS Background-color attribut

So lets build our function called "checkcolor()". First we need a document.getElementById for the user input. Then we need one for the block. Mine looks like this:

function checkcolor() {
var color = document.getElementById('inputcolor').value;
var elem = document.getElementById('block');

"Color" is the user's input and "elem" is the element we will apply it to. Now we need to access the background-color attribute of "elem". We do that by writing this:

elem.style.backgroundColor = color;

This sets the background-color of #block to whatever the variable 'color' is equal too which is set by the user when he/she writes something. Altogether it should look like this:

<html>
<head>
<title> Change a block's color </title>
<style>
#block {
height: 100px;
width: 100px;
border:solid black 2px;
}
</style>

<script>
function checkcolor() {
var color = document.getElementById('inputcolor').value;
var elem = document.getElementById('block');
elem.style.backgroundColor = color;
}
</script>

</head>
<body>
<p>What color should this block be?</p>
<p><i>Hint: Type in a color name like 'blue' or 'purple' or a hex code like '#2594f8'</i></p>
<p><input type="text" id="inputcolor"></p>
<p><input type="button" value="Shazaam!" onclick="checkcolor()"></p>
<div id="block">
<p>heres a block</p>
</body>
</html>
